# Parabola Castle

A one-page game for practicing the vertex form of a quadratic, `y = a(x − h)² + k`.

For each equation, students:

1. Identify the vertex `(h, k)`
2. Decide whether the parabola is reflected over the x-axis (opens down when `a < 0`)
3. Name the horizontal shift (left / right / none, and how many units)
4. Name the vertical shift (up / down / none, and how many units)

Each correct answer adds a piece to a castle blueprint. Right on the first try earns a gold stone; right on the second try earns a regular stone; after two misses the answer is shown and the piece goes in as a patched stone. Wrong answers get targeted hints (sign flip inside the parentheses, swapped h and k, stretch vs. reflection, and so on). After each stone, a graph shows the shift from the parent `y = x²` to the vertex.

Difficulty ramps across the 10 stones: one shift with `a = ±1`, then both shifts, then stretch factors like `2`, `−3`, `½`.

Open `index.html` in any browser. No install or internet needed beyond the web fonts.
